Игра «Змейка» (Snake)

Настольная аркадная игра «Змейка», написанная на языке Python с использованием стандартной библиотеки `tkinter`. Проект выполнен в тёмной контрастной стилистике с кастомной пиксельной графикой.

Управление
Стрелки (`↑`, `↓`, `←`, `→`) или W, A, S, D — изменение направления движения змейки.

Есть три типа яблок с разной ценностью:
Зелёное яблоко — +10 очков (не исчезает со временем).
Жёлтое яблоко — +20 очков (ограничено по времени).
Красное яблоко — +30 очков (быстро исчезает).

Запуск проекта
Для запуска требуется только установленный Python 3 (сторонние библиотеки не нужны).
