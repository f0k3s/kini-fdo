# Простой калькулятор на Python

Лабораторная работа № 2 «Система контроля версий».

Консольная программа складывает, вычитает, умножает и делит два числа.
Нужен Python 3. Сторонние библиотеки не требуются.

## Запуск

Откройте терминал в папке `EgorT351/calculator` и выполните:

```bash
python calculator.py
```

В Windows также можно использовать `py calculator.py`, в Linux —
`python3 calculator.py`.

Введите два числа, затем знак операции: `+`, `-`, `*` или `/`.
Для дробной части используйте точку, например `2.5`.
После результата введите `д` для нового вычисления или `н` для выхода.
После ошибки программа снова запрашивает числа. Ctrl+C завершает работу.

Пример: числа `5` и `3`, операция `+` → `Результат: 8`.

Обрабатываются неверное число, неизвестная операция, деление на ноль,
неконечные числа и переполнение результата. Вывод округляется до шести
значащих цифр стандартным форматом `g`; вычисления используют тип `float`.

## Выполненные проверки

Проверены все четыре операции: 5 + 3 = 8, 10 - 4 = 6,
6 * 7 = 42, 20 / 5 = 4; деление на ноль и текст вместо числа.
Подтверждены повторное вычисление и завершение программы.
